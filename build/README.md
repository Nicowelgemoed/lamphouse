# Building Lamphouse and Answer Print

Everything in `dctl/` is generated by these scripts from public data. You only need this folder to change the
model, retune it, or add stocks.

## Setup

```bash
cd build
python -m pip install -r requirements.txt
git clone https://github.com/andreavolpato/spektrafilm third_party/spektrafilm
```

The data path can be overridden with `SPEKTRAFILM_DIR`. Credits and version live in `config.py`.

## Build

```bash
python export.py     # -> ../dctl/AnswerPrint.dctl and ../dctl/Lamphouse.dctl
```

## Files

| File | What it does |
|---|---|
| `data.py` | Loads the spektrafilm profiles and light sources onto a common spectral grid, filling gaps |
| `model.py` | The reference film chain in NumPy: capture fit, negative, interlayer effect, printer, print, projection, printer balance |
| `export.py` | Calibrates every stock pairing and bakes the tables into both templates; computes Lamphouse's input and display matrices |
| `templates/answerprint.dctl` | Answer Print kernel |
| `templates/lamphouse.dctl` | Lamphouse kernel: input decoding, film engine, display transform |
| `set_author.py` | Fills your name and GitHub user into the credits, then rebuilds |
| `tests/harness.py` | Compiles a DCTL as C on the CPU and runs it over an image |
| `tests/reference.py` | Cross-check against the spektrafilm simulator (needs spektrafilm installed) |
| `tests/scene.py`, `tests/render.py` | Synthetic test scene and CPU renders of it |

## Tests worth running after a change

`tests/harness.py` compiles the exact DCTL source, so the DCTLs can be compared number-for-number with `model.py`
and with each other. It also enforces Resolve's rule that UI parameters and `TIMELINE_FRAME_INDEX` only exist inside
`transform()`, the mistake a GPU build reports as an undeclared identifier.

1. Answer Print vs `model.py` on ColorChecker patches and random colours across 16 stops, all 8 stock pairs.
2. Lamphouse vs Answer Print at the reference display (Rec.709, dark surround) for every look, with halation and
   grain on: should agree within about 0.002 code value.
3. Lamphouse input decoding vs colour-science's log curves for all 8 input spaces.
4. Lamphouse PQ and HLG grey ramps: monotonic and rolling into the peak.
